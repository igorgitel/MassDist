# MassDist — Majorant_v2

Event-driven Monte Carlo for coagulation and fragmentation cascades: a thinning
scheme with a dynamic majorant, used to measure the steady-state spectral index
`alpha` and the growth exponent `b`.

*Snapshot of 2026-08-21. The constant-kernel runs are still in progress; the
numbers recorded in `STATE.md` are those of the geometric-kernel runs.*

Everything here is **conservative**: one simulated particle stands for exactly one
physical particle for the whole run, nothing is resampled or cloned, and the
reported `mass_drift` is identically zero. Anything else is a bug, not a
fluctuation.

## Engines

**`BF_v_no_resampling_v4.py`** — cold engine. A run starts from the initial
condition and goes until it stops; there is no checkpoint, so the accessible age
range is bounded by the length of that single run.

**`BF_warm_start_v5.py`** — the same scheme with checkpointing. A run can be
saved and resumed with `START="state"`, and `t_origin` accumulates the time of all
previous legs, so ages carry across the seam and `tau` is not truncated by the
length of the measuring run. Working order: `cold` → test stationarity → `state`
→ test again → measure.

**`BF_analysis.py`** — the measurement layer: spectra, isochrones, generation
histograms, fits, stationarity test, `add_last_run`. Imported by every analysis
notebook, so nothing is defined twice.

## Run notebooks

Each writes one `runs/*.npz` and is read back by the analysis notebook of the
same name.

**`Run_closed_no_resampling`** — closed box, both processes, engine v4. No source
and no sink, so total mass is fixed and only its distribution evolves. Tests
`alpha = -(1+lambda)`, `b = 1/(1-lambda)`. The price of carrying no weights is
range: `N_i >~ 10^(3+D)` for `D` decades.

**`Run_open_coagulation_conservative_constant`** — engine v5, checkpointed,
`lambda = 0`. No synthetic seeding, by design: the observable here is age, and a
seeded body has none, so an invented age would enter the measured quantity
directly.

**`Run_open_coagulation_conservative_geometric`** — engine v4, one cold run.

**`Run_open_fragmentation_conservative_constant`** — local rule only, `f = 0.3`,
engine v5, seeding removed. At `lambda = 0` theory gives `alpha = -1.5` and
`b = 2`; the amplification `db/dalpha = b^2` is 4 here against 36 on the
geometric kernel, which is the one place the constant kernel is objectively more
convenient.

**`Run_open_fragmentation_conservative_geometric`** — the notebook the constant
one was derived from.

Open configurations test `alpha = -(3+lambda)/2`, `b = 2/(1-lambda)`. Coagulation
injects at `m_inj` and absorbs above `m_sink`; fragmentation injects large bodies
and absorbs below. The two share both exponents exactly — only the direction of
the drift changes.

## Analysis notebooks

Six, one per configuration, each rebuilt entirely from the stored `.npz`. No
simulation is repeated, so a figure can be changed without paying for the run
again. Every fit is performed on raw `dN/dm`; the compensation to `m^2 dN/dm` is
applied at draw time only, so the reported index is never the compensated one.

**`PRL_two_panel_fragmentation_coagulation`** — the two geometric-kernel PRL
blocks stacked on a shared mass axis, fragmentation above and coagulation below.
Both boxes span `m = 1 ... 1e6` with the flux running in opposite directions,
which is the content of the figure rather than a matter of layout. Reads two
`.npz` and draws; writes nothing.

## Publishing

`sync_to_git.py` in the working folder copies the manifest into this repository,
strips notebook outputs, regenerates `STATE.md`, commits and pushes. Default is a
dry run.
